# Benben Tours

Open `index.html` to reach the website. It redirects to `benben-tours.html`.

- `benben-tours.html` contains the page content.
- `styles.css` contains the page styles.
- `script.js` contains interactive behavior and translations.
- `translations.js` contains offline translations for the remaining page text and tour-photo captions.
- `images/tours/` contains locally stored tour gallery photos.
- `PHOTO-CREDITS.md` lists the photo authors, licenses, and source pages.

The site is configured for GitHub Pages from the `main` branch and repository root.
